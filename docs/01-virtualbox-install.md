# Step 1: Installing VirtualBox

## What is VirtualBox?
VirtualBox is a free, open-source virtualization tool that lets you run an operating system (like Kali Linux) inside a "virtual machine" on top of your existing OS — no dual-booting or extra hardware needed.

## Download
Go to the official VirtualBox downloads page: https://www.virtualbox.org/wiki/Downloads

Choose the installer for your host OS:
- Windows hosts
- macOS / macOS Apple Silicon hosts
- Linux distributions

## Installation steps

### Windows
1. Run the downloaded `.exe` file
2. Click through the setup wizard (default options are fine for most users)
3. Allow the network interface installation prompt if it appears
4. Launch VirtualBox once installation completes

## Verify installation
Open VirtualBox. You should see the VirtualBox Manager window.

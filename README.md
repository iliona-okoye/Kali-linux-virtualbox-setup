# Kali Linux on VirtualBox — Setup Guide

A step-by-step guide to installing Kali Linux as a virtual machine using Oracle VirtualBox, built for cybersecurity practice and learning.

## What's covered
- Installing VirtualBox on your host machine
- Downloading the official Kali Linux image
- Creating and configuring the virtual machine
- Installing Kali Linux inside the VM
- Post-install setup (Guest Additions, updates, snapshots)

## Prerequisites
- A computer running Windows, macOS, or Linux
- At least 4GB RAM available for the VM (8GB+ recommended)
- 20GB+ free disk space
- Virtualization enabled in BIOS/UEFI (Intel VT-x or AMD-V)
